# Sarah Wong — Personal Site

A minimal Next.js (App Router, TypeScript) personal homepage for Sarah Wong, a senior at UH Mānoa studying Korean and SLS.

## Stack

- [Next.js](https://nextjs.org/) App Router
- TypeScript
- Plain CSS (`app/globals.css`) — no Tailwind or UI libraries
- No database

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Deployed to Vercel from the `main` branch.
